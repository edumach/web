
# Sémantické HTML a přístupnost

## Co se naučíš

- používat sémantické prvky
- vytvářet přístupnější weby

🌐 Tutoriál: [https://www.w3schools.com/html/html5_semantic_elements.asp](https://www.w3schools.com/html/html5_semantic_elements.asp)

## Cvičný projekt

Nahraď obecné prvky vhodnými sémantickými elementy:

```html
<header>
<nav>
<main>
<section>
<footer>
```

Zkontroluj:

- strukturu nadpisů,
- alternativní texty,
- funkčnost odkazů.

## Rozšiřující úkol

Zkus používat stránku bez CSS.

Dokážeš stále poznat:

- hlavní nadpis?
- navigaci?
- jednotlivé sekce?

Pokud ano, HTML je navrženo správně.
