# Opakovací cvičení

> Jednostránkový web

**Časová dotace:** 2 vyučovací hodiny

**Na stránce se musí objevit:**

- hlavička (header)
- hlavní obsah
- alespoň jeden obrázek
- alespoň jeden seznam
- alespoň jeden hypertextový odkaz
- barevné řešení (2–3 barvy)
- patička

**Povinné CSS prvky (minimální):**

- šířka obsahu stránky 600–800 px a na střed
- barva textu
- barva pozadí
- nastavení písma
- zarovnání
- základní úprava obrázku (např. šířka)
- použitá alespoň jedna CSS třída
- využití alespoň jednoho `:hover` ([jak to funguje](https://www.w3schools.com/cssref/sel_hover.php))


**Odevzdání:**

- Složku s projektem pojmenujte **prijmeni-web1**, zazipujte a odevzdejte podle zadání vyučujícího. 
- Nehodnotím, jak rychle web vytvoříte. Hodnotím, jak kvalitně je navržený a zda splňuje zadání.
- V každém případě jej musíte odevzdat včas (před koncem termínu).

**Doporučení:** 

Nejprve vytvořte HTML kód stránky. Až když bude stránka obsahově hotová, začněte ji stylovat pomocí CSS. Průběžné střídání práce na HTML a CSS obvykle vede ke zbytečným chybám a zdržování.

## (1) Osobní mini vizitka

- Nadpis se jménem
- Fotka / avatar
- Krátké představení
- Seznam koníčků
- Oblíbený citát
- Odkazy (Instagram, GitHub...)

## (2) Herní nebo filmová fan stránka

- Obrázek
- Krátké představení
- Seznam postav / funkcí
- Tři důvody, proč je to nejlepší

## (3) Fiktivní produkt / reklama

Energetický nápoj pro programátory, Herní klávesnice, „Chytrý batoh pro studenty“...

- Název produktu
- Slogan
- Obrázek
- 3 výhody (v odrážkách)
- Tlačítko/odkaz „Koupit“

## (4) Školní turnaj nebo akce

Turnaj v něčem dle vlastního výběru, IT workshop, Filmová noc, Výlet...

- Název akce
- Propagační foto
- Datum a místo
- Program (seznam)
- Přihlašovací odkaz 

## (5) Cestovatelská mini stránka

ČR, Evropa nebo svět

- Obrázek města/místa/lokality
- Krátké info
- 3 místa, která stojí za návštěvu (+ foto)
- Odkaz na mapu
- Informační video (YouTube)

## (6) Stručná historie IT zařízení

Název, popis a souvislosti, fotografie, zajímavosti...

- Myš
- CD disk
- Webová kamera
- Pevný disk (HDD)
- Disketa (FDD)
- E-ink 

## (7) Stránka „Top 5 něčeho“

- Hry
- Seriály
- Aplikace pro studium
- Rekordů
- Staveb
- ...
