
# Web a internet

Webové stránky dnes patří mezi nejdůležitější způsoby sdílení informací. Během tohoto bloku se naučíš vytvářet vlastní webové stránky pomocí HTML a CSS. 

Nepůjde o to učit se zpaměti stovky značek nebo vytvořit dokonalý web. Cílem je pochopit principy fungování webu a dokázat vytvořit jednoduchou, přehlednou a funkční webovou prezentaci. Zejména:

- jak funguje web,
- jak spolu komunikují prohlížeč a server,
- jak vzniká webová stránka,
- jak vytvořit vlastní web.
- jak upravit jeho vzhled

**Nebudeš se učit pouze web psát. Naučíš se webu rozumět.**
