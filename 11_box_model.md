
# Box model (CSS)

> Prostor kolem elementů
> Každý element je obdélník

## Co se naučíš

- připojit CSS
- měnit vzhled webu
- používat box model


```text
┌──────────────────────────┐
│          margin          │
│  ┌────────────────────┐  │
│  │       border       │  │
│  │  ┌──────────────┐  │  │
│  │  │    padding   │  │  │
│  │  │  ┌────────┐  │  │  │
│  │  │  │ content│  │  │  │
│  │  │  └────────┘  │  │  │
│  │  └──────────────┘  │  │
│  └────────────────────┘  │
└──────────────────────────┘
```



## Cvičný projekt

Vytvoř soubor:

```text
css/style.css
```

Připoj ho ke stránce.

Vyzkoušej:

```css
color
background-color
font-family
padding
margin
border
```
